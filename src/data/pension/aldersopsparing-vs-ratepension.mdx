# Aldersopsparing vs. ratepension

Aldersopsparing giver ikke fradrag ved indbetaling, men udbetalingen er som udgangspunkt skattefri efter reglerne. Ratepension giver normalt fradrag ved indbetaling og beskattes ved udbetaling. Derfor handler valget om skatten både nu og senere, indbetalingsrammer, modregning og hvordan du ønsker pengene udbetalt.

## Sammenligning

| | Aldersopsparing | Ratepension |
|---|---|---|
| Fradrag ved indbetaling | Nej | Normalt ja inden for årets ramme |
| Skat af afkast | PAL-skat efter gældende regler | PAL-skat efter gældende regler |
| Udbetaling | Som udgangspunkt skattefri | Beskattes som personlig indkomst |
| Udbetalingsform | Kan typisk udbetales samlet eller i portioner | Udbetales i rater over en periode |
| Modregning | Har andre konsekvenser end skattepligtige pensionsudbetalinger | Kan påvirke indkomstafhængige ydelser |
| Indbetalingsramme | Årlig grænse, som afhænger af afstand til folkepension | Årlig fradragsramme |

Kontrollér altid årets beløb og betingelser hos [Skattestyrelsen](https://skat.dk/borger/fradrag/pensionsfradrag).

## Hvornår kan aldersopsparing være attraktiv?

Aldersopsparingen kan give fleksibel, skattefri udbetaling og kan være relevant som supplement til skattepligtige pensionsudbetalinger. Den årlige indbetalingsgrænse betyder, at den sjældent står alene. Læs [Aldersopsparing](/pension/aldersopsparing) for hele processen.

## Hvornår kan ratepension være attraktiv?

Ratepension kan være relevant, hvis fradraget har høj værdi under arbejdslivet, og du forventer en hensigtsmæssig skat ved udbetaling. Du binder samtidig pengene og accepterer skattepligtige udbetalinger senere. Se [Ratepension](/pension/ratepension).

## Det er ofte både-og

Mange kan bruge aldersopsparingen som fleksibelt supplement og ratepensionen til fradragsberettiget, løbende opsparing. En [livrente](/pension/livrente) kan dække den livslange del, mens frie midler giver adgang før pensionsalderen.

Vurder ordningerne sammen med arbejdsmarkedspension, folkepension, bolig og øvrig formue. Den bedste pensionsopsparing er en samlet udbetalingsplan — ikke den konto med den mest attraktive enkeltstående skatteregel.
